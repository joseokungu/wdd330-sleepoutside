# Travel Planner & Destination Explorer

## 1. Overview

For my final project, I would like to create a travel planning application. The goal of the application is to help users learn about different countries, view pictures of destinations, check weather conditions, and save places they would like to visit.

I chose this project because I enjoy traveling and discovering new places. I also wanted a project that would allow me to work with different APIs and practice the JavaScript concepts we have learned during this course.

## 2. Target Audience

This application is intended for people who are interested in traveling and exploring new destinations. It could be useful for students, families, and anyone planning a trip who wants quick access to information about a country or city.

## 3. Major Functions

### 1. Search for a destination
Users can search for a country or city and receive information about it.

### 2. Display country information
The application will show details such as the capital city, population, currency, and languages.

### 3. Show country flag
The country flag will be displayed with the destination information.

### 4. Display current weather
Users can see the current weather conditions for the selected destination.

### 5. Show destination photos
The application will display photos related to the destination.

### 6. Save favorite destinations
Users can save destinations to a favorites list.

### 7. Create a travel plan
Users can create their own travel plans and notes.

### 8. View recent searches
The application will keep track of recently searched destinations.

## 5. External Data

### API 1: REST Countries API
This API will provide information about countries, including population, capital city, currencies, languages, and flags.

### API 2: Unsplash API
This API will provide images related to destinations and countries.

### Data Stored

Using Local Storage, I plan to save:

- Favorite destinations
- Travel notes
- Recent searches
